# Requirement Traceability Matrix

## Overview
This **Requirement Traceability Matrix (RTM)** maps the core business and functional requirements defined in the Enterprise Supply Chain Case Study to their corresponding benchmark datasets, prototype implementation components, and empirical verification criteria.

---

## Traceability Table

| Requirement ID | Core Module | Case Study Requirements | Datasets Used | Prototype Implementation Scope | Verification & Acceptance Criteria |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **REQ-01** | **Enterprise Data Pipeline** | Ingest Historical Sales, Warehouse Inventory, Supplier Performance, Product Master Data, Promotions, Holidays, Weather Data, Regional Events, and Delivery Times | Olist, DataCo, Rossmann, M5 | Python ETL pipeline utilizing Pandas and SQLAlchemy to clean, merge, and store multi-source dataset tables into SQLite/PostgreSQL | Successful ingestion of all 4 datasets into unified SQL tables; 0 schema validation errors; passing automated ETL integration tests |
| **REQ-02** | **Feature Engineering** | Generate Sales Velocity, Seasonality Index, Promotion Impact, Lead Time, Supplier Reliability Score, Product Lifecycle Stage, Demand Volatility, Regional Patterns, and Holiday Effects | Rossmann, M5, DataCo, Olist | Time-series feature engineering pipeline constructing lag features, rolling averages, seasonality indices, holiday flags, and lead-time variability metrics | Consolidated feature store generated without null/NaN leakages; feature correlation and importance benchmarks verified |
| **REQ-03** | **Demand Forecasting Engine** | Predict Daily Demand, Weekly Demand, Monthly Demand, Seasonal Peaks, Regional Demand, and Product Category Demand | Rossmann, M5 | Multi-model forecasting pipeline implementing LightGBM, XGBoost, and Prophet models with multi-horizon evaluation | Forecast accuracy evaluation achieving WAPE < 15% across test horizons; point and interval forecast endpoints operational |
| **REQ-04** | **Inventory Optimization Engine** | Recommend Reorder Point (ROP), Safety Stock, Economic Order Quantity (EOQ), Warehouse Allocation, Inter-Warehouse Transfers, and Procurement Quantity | DataCo, Olist, M5 | Analytics engine applying statistical inventory formulas ($Z \cdot \sigma_d \cdot \sqrt{L}$) and EOQ equations parameterized by lead-time distributions | Reorder points, safety stock levels, and EOQ values generated per SKU/location node; zero negative inventory targets |
| **REQ-05** | **Supply Chain Risk Engine** | Detect Supplier Delay Risk, Stockout Risk, Overstock Risk, Slow-Moving Inventory, Dead Inventory, and Demand Anomalies | DataCo, Olist, M5, Rossmann | Anomaly detection algorithms and classification rules evaluating delivery delay variance, stock turn rates, and demand volatility spikes | High-risk orders and inventory items correctly flagged; risk classification REST API returning accurate risk scores |
| **REQ-06** | **Scenario Simulation** | Simulate Supplier Failure, Price Increase, Holiday Sales, New Product Launch, Transportation Delay, and Demand Surge | DataCo, Rossmann, M5 | Parameterized simulation module allowing real-time interactive adjustments of demand and lead-time shocks to predict fill-rate impacts | Interactive scenario recalculation (< 2s latency); dynamic forecast trajectory updates reflecting input stress parameters |
| **REQ-07** | **Executive Dashboard** | Display Forecast Accuracy, Inventory Health, Warehouse Utilization, Fill Rate, Stockout Probability, Procurement Recommendations, and Supply Chain KPIs | All Datasets (Unified) | Web visualization UI (Streamlit / React) displaying interactive KPI scorecards, demand charts, inventory heatmaps, and recommendation tables | Dashboard renders cleanly with working dynamic filters (category, location, timeframe) and live metric cards |
| **REQ-08** | **Alert Center** | Generate alerts for Low Inventory, Overstock, Demand Spike, Supplier Delay, Warehouse Capacity Risk, and Forecast Drift | All Datasets & ML Engine | Event-monitoring module scanning inventory levels and risk outputs to generate prioritized alert notifications | System correctly triggers and categorizes alerts when safety stock or model drift thresholds are breached |
| **REQ-09** | **ML / MLOps Components** | Implement LightGBM, XGBoost, Prophet, Time Series CV, Feature Selection, Bayesian Hyperparameter Optimization, MLflow, Model Registry, and Data Drift Detection | Rossmann, M5 | MLflow integration for experiment tracking, metric logging, model artifact registration, and data distribution drift detection | Runs and model artifacts logged in MLflow registry; drift detection module successfully detects synthetic distribution shifts |
